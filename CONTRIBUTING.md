# Contributing to 100 Days of AI Security

## What we want

- **Dead link fixes** — a paper moved, a tool got archived, a CVE reference is wrong.
- **Better primary sources** — a clearer paper, a more current benchmark, a more accurate CVE for a day's task.
- **Day reordering/splitting suggestions** if a day is clearly too big or too small relative to the others.
- **Translations** of the day list into other languages.

## What we don't want

- New days that pad the count — every day already maps to a specific resource in [`ai-security-resources`](https://github.com/ppradyoth/ai-security-resources). If you want to add breadth, contribute there first.
- Promotional links to tools/products without a clear, personally-verified AI security use case.
- Unverifiable claims (no link, no CVE number, no paper).

## How to submit

1. Fork this repository.
2. Create a branch: `git checkout -b fix/day-N-description`.
3. Make the change, keeping the existing `- [ ] **Day N** — task — [link](url)` format.
4. Open a PR explaining what was wrong and what you changed it to, with a link proving the new resource is current.

## Questions

Open an issue. Keep it public and async so the answer helps the next person too.
